# Overview

This extension includes the music from the Well-Tempered Clavier,
books 1 and 2, by Johann Sebastian Bach.

The music was loaded using the `ly2pg` extension from the LilyPond
sources in [Rother, K. 2015. An 'open source' open score edition of
Bach's Well-tempered Clavier. Music score. University of Cape
Town.](hdl.handle.net/11427/13106).
